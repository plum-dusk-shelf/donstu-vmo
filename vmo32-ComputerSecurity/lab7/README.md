# Graphic Key App

Учебное приложение для регистрации и входа по **классическому графическому ключу**, как на телефонах (Pattern Lock).

## Возможности

- регистрация пользователя по имени и графическому ключу 3x3;
- последовательность точек сохраняется как цифровой отпечаток SHA-256;
- Android-подобная логика: если линия перепрыгивает через центральную точку, она автоматически добавляется;
- проверка входа по точному совпадению или похожести (>= 80%);
- 3 попытки входа;
- хранение данных пользователей в зашифрованном файле `users.enc`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m graphic_key_app.main
```

Файлы `secret.key` и `users.enc` создаются автоматически в папке приложения.
