Тестирование сервлета информации о сессии

Это простая HTML-страница для взаимодействия с сервлетом, который показывает информацию о сессии.

Нажмите на кнопку ниже, чтобы перейти к сервлету и увидеть информацию о вашей сессии:

Перейти к информации о сессии

Как это работает:

  • При первом посещении сервлета создается новая сессия
  • Сервлет запоминает количество ваших запросов в текущей сессии
  • На странице отображается ID сессии, время ее создания и текущее время на сервере
  • Обновите страницу, чтобы увеличить счетчик запросов
