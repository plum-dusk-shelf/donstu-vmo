1. `Player` - конструктор для создания объектов игроков. Принимает один аргумент `color`, который может быть равен `"white"` или `"black"`. Содержит следующие свойства:
* `checked` - булево значение, указывающее, находится ли король игрока под шахом.
* `color` - цвет игрока.
* `castled` - булево значение, указывающее, совершал ли игрок рокировку.
* `king` - объект короля игрока.
* `kingMoved` - булево значение, указывающее, совершал ли король игрока ход.
* `promote` - объект, содержащий информацию о пешеке, которая была преобразована.
* `moved` - объект, содержащий информацию о последнем ходе игрока.
1. `turn` - переменная, содержащая текущий номер хода.
2. `white` и `black` - объекты игроков, созданные с помощью конструктора `Player`.
3. `currentPlayer` - переменная, содержащая объект текущего игрока.
4. `SquareObject` - конструктор для создания объектов клеток шахматной доски. Принимает 6 аргументов:
* `x` - горизонтальная координата клетки.
* `y` - вертикальная координата клетки.
* `color` - цвет клетки.
* `selected` - булево значение, указывающее, выбрана ли клетка.
* `element` - элемент HTML-документа, соответствующий клетке.
* `piece` - объект шахматной фигуры, находящейся на клетке.

* `setPiece` - устанавливает шахматную фигуру на клетку.
* `unsetPiece` - удаляет шахматную фигуру с клетки.
* `update` - обновляет HTML-элемент, соответствующий клетке.
* `select` - выбирает клетку.
* `deselect` - снимает выделение с клетки.
* `hasPiece` - возвращает булево значение, указывающее, есть ли шахматная фигура на клетке.

1. `Piece` - конструктор для создания объектов шахматных фигур. Принимает 4 аргумента:
* `x` - горизонтальная координата фигуры.
* `y` - вертикальная координата фигуры.
* `color` - цвет фигуры.
* `type` - тип фигуры.


* `capture` - устанавливает свойство `captured` в `true`, указывающее, что фигура была съедена.
1. `Castle`, `Knight`, `Bishop`, `Queen`, `King`, `Pawn` - конструкторы для создания объектов конкретных шахматных фигур. Наследуются от конструктора `Piece` и переопределяют метод `isValidMove`, проверяющий, является ли ход фигуры допустимым.
2. `setup` - функция, выполняющаяся при загрузке страницы и инициализирующая шахматную доску и расположение фигур на ней.
3. `showError`, `closeError`, `showEnd`, `getSquare`, `squareClicked`, `move` - вспомогательные функции, используемые для взаимодействия с пользователем и обработки ходов.
4. `isCheckmate` - функция проверяющая, является ли текущая позиция мат.
