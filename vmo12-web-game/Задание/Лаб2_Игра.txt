Лабораторная работа №2.
Создать игру на Java-Script. Варианты заданий (можно выбрать любое):

1. Тетрис
2. Lines
3*. Пятнашки
4*. Крестики-нолики (игра с компьютером) на поле 15x15. Первый, выстроивший в ряд 5 своих фигур по вертикали, горизонтали или диагонали, выигрывает.
5. Червяк и яблоки. По игровому полю ползает червяк, который при съедании яблока увеличивается в размерах. Сложность игры определяется количеством препятствий и необходимым размером червяка для перехода на следующий уровень.
6. Ралли. Внизу (или слева) игрового поля находится машина, которой вы управляете, на нее надвигается дорога с препятствиями. Сложность игры определяется количеством препятствий и скоростью движения.
7. Ралли со стрельбой. Вместо препятствий есть враги, которые таранят вас (или стреляют по вам) и вы их отстреливаете.
8. Охота (на попадание мышкой по мишеням) В пределах игрового поля в разных местах появляются мишени, игрок должен по ним попасть курсором. Сложность определяется скоростью появления и количеством мишеней. 
9. Galaxian. По экрану двигается группа объектов, они перемещаются влево, вправо и вниз. Внизу игрового поля двигается пушка, выстрелами которой нужно сбить все объекты. Сложность определяется скоростью перемещения и приближения объектов. 
10*. Морской бой (игра для 2-их) Позиции кораблей выставляет компьютер, игроки не знают позиций своих кораблей, а на экране две карты - карта "атаки" для первого и второго игрока.
11. Балда. Необходима начальная база слов. При введении слова, которое отсутствует в базе, должен задаваться запрос о разрешении добавить его в базу. ajax  jquery
12. Сапер. Левой кнопкой мыши открываем клетку. Правой кнопкой мыши (или левой с зажатым Ctrl) - помечаем мину. 
13. Тетрис с шариками. В стакан падают группы из трех цветных шариков, при совпадении цвета более 3х шариков эти шарики данного цвета исчезают. Шарики осыпаются на место исчезнувших (т.к. у шариков нет углов они будут скатываться вниз, если ярусом ниже их ничто не удерживает)
14. Pacman. Герой двигается и поедает точки. Ему должны мешать препятствия и другие герои.
15*. Карточный пасьянс (любой)
16. Бармен. Отправлять кружки с пивом по 2-8(сложность) стойкам, по которым приближаются жаждущие (скорость движения и количество нарастает).
17*. FILLER (игра для 2-их) Начальное квадратное поле заполнено разноцветными квадратиками. В левом верхнем углу находится "захваченая область" первого игрока, в правом нижнем - второго. (Изначально у каждого по одной клетке.) Поочередно игроки выбирают цвет, в который перекрашивается их "захваченная область". Клетки, примыкающие к "захваченной области" и имеющие тотже цвет - считаются захваченными. Побеждает тот, кто захватил больше 50% клеток.
18. Лабиринт (лабиринт должен генерироваться АВТОМАТИЧЕСКИ). С каждым уровнем размер лабиринта все больше, а времени дающегося на его прохождение - все меньше.
19. TOPPLER. На экране изображены N на M островков (или лилий). Островки периодически начинают медленно уменьшатся в размерах пока не исчезнут совсем, через случайное время на этом месте вновь появляется остров, теперь - медленно увеличиваясь, Вы управляете лягушкой (с клавиатуры), которая может перепрыгивать с острова на остров, если остров под лягушкой исчез, или лягушка прыгнула с острова на пустое место - игрок проиграл. Цель игры - продержатся как можно дольше пока нарастает скорость появления/исчезновения островов.
20*. Поле чудес. Должна быть заполнена база вопросов и ответов.
21*. Шашки (игра для 2-их).
22*. Шахматы  (игра для 2-их).
23. Арканойд (шарик должен двигаться ПЛАВНО). Сложность игры определяется скоростью передвижения шарика.
24*. Игровой автомат "однорукий бандит" (барабаны должны останавливаться ПЛАВНО, запуск автомата при клике по ручке - ручка должна повернутся)

25. По выбору студента (обязательно согласовать с преподавателем!).


Общие требования:
Кнопки: новая игра, таблица рекордов.
Подсчет очков (и/или времени игры) и вывод их по завершению игры, если очков набрано достаточно для попадания в таблицу рекордов - спросить у пользователя его имя.
Ведение таблицы рекордов: таблица из 10 лучших партий в порядке убывания (имя - очки и/или время игры). Данные хранить в Cookie.
Изменение уровней сложности ("*" в номере - игра не предполагает уровней сложности).
НИКАКОЙ ASCII-графики!


ОТЧЕТ должен включать - титульный лист, лист задания, скриншот, исходный код.
